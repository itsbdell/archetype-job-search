# Create or Refine a Positioning Brief

Work on the positioning brief for the **$ARGUMENTS** archetype.

If no archetype was specified, list the user's defined archetypes (from `materials/profile.md`) and ask which one to work on.

## Context

Read these files first:
1. `materials/profile.md` — the user's background and career story
2. `archetypes/{archetype}/positioning-brief.md` — existing brief, if any
3. `templates/positioning-brief.md` — the template structure

## If Creating a New Brief

Interview the user to build the positioning. Ask about:

1. **Core positioning:** "If you had one sentence to explain why you're the right person for these roles, what would it be?"
2. **Lead-with points:** "What are the 3-4 things you'd want a hiring manager to know first?"
3. **Proof points:** "For each of those, what's the specific evidence? Metrics, outcomes, names?"
4. **Differentiator:** "What makes your combination of skills rare? What do most people in this space lack that you have?"
5. **Cover letter angles:** "What's the narrative hook? How does your career story connect to this type of role?"
6. **Target companies:** "What kinds of companies hire for this archetype? Any specific names?"
7. **Keywords:** "What terms would appear in job descriptions for these roles?"

Write the brief to `archetypes/{archetype}/positioning-brief.md` using the template structure.

## If Refining an Existing Brief

Read the existing brief and present a brief assessment:
- What's strong about the current positioning?
- What's vague, generic, or missing?
- Are the proof points specific enough (metrics, outcomes)?
- Does the differentiator actually differentiate, or could anyone say it?

Then work through improvements with the user:
- Sharpen the core positioning — make it more specific and memorable
- Upgrade proof points with better metrics or more concrete examples
- Tighten the differentiator — what's the rare combination?
- Add or refine cover letter angles
- Update target companies based on research done so far

Save the updated brief.

## Quality Checks

Before finishing, verify:
- [ ] Core positioning is one sentence, specific, and not interchangeable with anyone else
- [ ] Lead-with points are concrete (not "proven leader" but "grew team from 3 to 25")
- [ ] Proof points have at least some metrics or specific outcomes
- [ ] Differentiator passes the "would a competitor say this?" test — if yes, sharpen it
- [ ] Keywords actually appear in real job postings for these roles
- [ ] Everything in the brief came from the user — nothing fabricated

## Rules
- Write in the user's voice, not in resume-template voice
- Push for specificity — "managed a team" → "managed a team of 12 engineers shipping a real-time analytics platform"
- Don't pad weak areas — if they're thin on proof points for something, mark it `[TODO]` or discuss whether the archetype needs rethinking
- The brief is a *source document* for all applications under this archetype — it needs to be rich enough to generate multiple tailored resumes and cover letters
